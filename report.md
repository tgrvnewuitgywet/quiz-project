Цель: Получить практические навыки совместной работы с Git и GitHub, создания веток, выполнения коммитов, отправки изменений в удалённый репозиторий, создания Pull Request, слияния веток и разрешения конфликтов.

## 5. Хронология работы

1. Создан репозиторий quiz-project.
2. Созданы рабочие ветки feature/q1-q2, feature/q3-q4 и feature/q5-q6.
3. Добавлены вопросы и файл с правильными ответами.
4. Созданы Pull Request и выполнено слияние изменений.
5. Созданы ветки для учебного конфликта в README.md.
6. Выполнено разрешение конфликта слияния.
7. Проведена финальная проверка структуры проекта и истории коммитов.

## 6. Использованные команды Git

| Команда | Назначение |
|---------|------------|
| git clone | Клонирование удалённого репозитория |
| git status | Проверка состояния рабочей директории |
| git checkout -b | Создание новой ветки и переключение на неё |
| git branch | Просмотр списка веток |
| git add | Добавление файлов в индекс |
| git commit | Сохранение изменений в истории |
| git push | Отправка изменений в удалённый репозиторий |
| git pull | Получение и объединение изменений |
| git merge | Слияние веток |
| git log --oneline --graph --all --decorate | Просмотр истории коммитов и слияний |

## 7. Скриншоты

1. Граф коммитов (git log --graph).
2. Список Pull Request.
3. Момент возникновения конфликта (маркеры в README.md).
4. Успешное разрешение конфликта и слияние веток.

## 8. Возникшие трудности и их решение

В ходе работы возникли трудности при выполнении команд Git, переключении между ветками и синхронизации локального репозитория с удалённым. Также потребовалось разобраться с разрешением конфликта слияния в README.md.

Для решения проблем проверялось состояние рабочей директории с помощью git status, история изменений с помощью git log, а также содержимое файлов после слияния. После проверки изменений выполнялись необходимые коммиты и отправка данных в удалённый репозиторий.

В результате практической работы были изучены основные возможности Git и GitHub для командной разработки.
